# Лицензии моделей и библиотек

Критерий допуска из правил (п. 3.7): запрещены технологии, исключительное право на которые принадлежит третьим лицам, **не передаётся через open-source лицензию и требует возмездного приобретения прав**. То есть запрещено то, что одновременно не open-source и платное.

Дата проверки лицензий: 20.09.2026. Источник: HuggingFace API (`cardData.license`), проверено запросом к `https://huggingface.co/api/models/<repo>`. Перед сборкой финального архива проверить ещё раз и приложить файл лицензии внутрь `model/`.

| YandexGPT-5-Lite-8B-instruct | `yandex/YandexGPT-5-Lite-8B-instruct` | 8B | `other` (собственная лицензия Яндекса) | **не проверена, читать текст лицензии до использования** | да, GGUF Q4_K_M |

Про YandexGPT: в карточке стоит `license: other`, то есть собственная лицензия, а не стандартная open-source. Формально критерий запрета двойной (не open-source **и** платная), и лицензия Яндекса бесплатная, но текст надо прочитать глазами до того, как модель попадёт в архив решения, и процитировать здесь пункт про коммерческое и конкурсное использование. Пока модель считается пригодной только для локальной генерации синтетики, но не для попадания внутрь сабмита.
